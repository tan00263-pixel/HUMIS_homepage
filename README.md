While working on this project, I got a refresher on HTML and CSS. After completing this project I gained more experience
and confidence with both. I definitely feel like I have a better understanding but still have to look some things up and
ask questions. This project challenged me to not get stuck up in stylistically design but rather paying more attention
to layout. When first beginning to work on this project outside of class it felt like trying to ride a bike for the
first time without training wheels.

I think one of the hardest parts of this project was staying organized. Once I started creating multiple files for
different pages it became more crucial to stay organized. Another challenge was labeling things. I have a million
different things on my computer labeled “Untitled” and this project helped me get into a better habit of properly
labeling things.

Being able to duplicate a previous page to create a new one felt like the easiest part of this project. There is not as
much code to write and it’s already organized so adding and changing parts didn’t feel as overwhelming or hard. I did
have to look back and forth a lot between the code we wrote in class and the code I was writing on my own. I think by
doing this I was able to see some patterns while working and gained a better understanding.

I hope that I will be able to apply this new knowledge to future projects in this class or maybe personal projects if
I’m feeling adventurous.
